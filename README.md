# Achievement Unlock Intro Generator

一个可部署到 GitHub Pages 的纯前端工具，用于生成 Liquid Glass 风格的“游戏成就跳出卡片”Logo 介绍图片。

## 产品定位

面向同人周边、游戏社群、活动视觉、新品发布、虚拟角色设定页等场景，用户无需设计软件，即可上传底图与 Logo，像视频发布 App 的封面裁切一样调整保留区域，并生成具有 Apple 风格液态玻璃质感的 300dpi PNG 图片。

## 核心功能

- 固定导出比例为参考图比例：`1932×1360px`
- 生成图结构拆分为后方底图和前方 Liquid Glass 成就卡片
- 上传底图，并支持底图缩放、水平位置、垂直位置和不透明度调整
- 上传 Logo，并支持 Logo 区域内缩放、水平位置、垂直位置调整
- 输入主标题、副标题和介绍文案，介绍文案支持手动换行
- 支持调整介绍文案显示文本框的宽度和高度
- 支持调节副标题到主标题、主标题到分隔线、分隔线到正文、正文行距等文字间距，并支持副标题 / 主标题 / 正文字距调节
- 默认去掉底部英文标签
- 文字排版保留游戏成就卡片风格
- 中间卡片采用 Apple macOS / iOS 系统面板取向的真实背景磨砂玻璃样式
- 去掉装饰弧线、粗内边框、毛边滤镜、固定粉蓝彩色描边和白色外发光，改为 2.5px 克制渐变描边、1px 顶部高光和 1px 底部暗边
- 玻璃深度控制背景模糊、玻璃染色与阴影强度；边缘色散仅保留最大 1px 的极轻微红蓝偏移；卡片透明度只控制玻璃染色层
- 所有滑杆调节均支持数字输入和单项复原，并支持一键复原全部调节项
- 上传底图后可自动生成多组强调色 / 文字色主题方案供一键应用
- 支持切换中文字体，也可上传自定义字体文件
- 所见即所得 SVG 预览
- 导出 300dpi PNG 和 SVG

## GitHub Pages 部署

仓库无需构建，直接使用静态文件即可：

1. 将代码推送到 GitHub 仓库。
2. 打开仓库 Settings → Pages。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/root`。
5. 保存后等待 Pages 发布。

## 本地预览

直接打开 `index.html`，或在仓库目录运行任意静态服务器。
