# Achievement Unlock Intro Generator

一个可部署到 GitHub Pages 的纯前端工具，用于生成 Liquid Glass 风格的“游戏成就跳出卡片”Logo 介绍图片。

## 产品定位

面向同人周边、游戏社群、活动视觉、新品发布、虚拟角色设定页等场景，用户无需设计软件，即可上传底图与 Logo，像视频发布 App 的封面裁切一样调整保留区域，并生成具有 Apple 风格系统磨砂玻璃质感的成就介绍卡片。

## 核心功能

- 固定导出比例为参考图比例：`1932×1360px`
- 生成图结构拆分为后方底图和前方 Apple 系统磨砂玻璃成就卡片
- 全部参数按内容、底图、Logo、Liquid Glass、排版与预览重新分组；每个滑杆均提供当前数值输入和单项复原
- 底图与 Logo 均支持点击上传、拖拽、剪贴板粘贴、替换、移除、缩放与位置裁切；文件校验支持 PNG / JPEG / WebP 和 20MB 上限
- 画布中可直接点击底图或 Logo 后拖动定位、滚轮缩放，并与滑杆实时双向同步；提供适应、填满、居中、复原快捷动作
- Logo 提供默认悬浮和玻璃底座两种视觉样式，切换不影响裁切参数
- 三种玻璃预设：清透、标准、深色；手动修改玻璃参数后自动标为“自定义”
- 真实背景模糊采用 SVG `feGaussianBlur`，结合饱和度和对比度微调；轮廓保持 2.5px 渐变外边框、1px 同几何高光与内侧暗边
- 文案使用 Canvas 真实字体测量进行中英文混排与手动换行处理；标题自动缩小，正文溢出以省略号和编辑器提示明确反馈
- 支持撤销 / 重做（最多 30 步）、Ctrl/Cmd 快捷键、本地参数恢复，以及 IndexedDB 素材恢复
- 支持系统字体和自定义字体；自定义字体 Data URL 内嵌到导出 SVG，PNG 导出前等待字体和图片解码
- PNG 导出写入 300dpi 对应的 `pHYs` 元数据（11811 pixels/m），包含 loading、成功与具体失败提示；SVG 与预览共享同一渲染结构
- 响应式移动端支持编辑 / 预览切换和固定导出操作栏

## GitHub Pages 部署

仓库无需构建，直接使用静态文件即可：

1. 将代码推送到 GitHub 仓库。
2. 打开仓库 Settings → Pages。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/root`。
5. 保存后等待 Pages 发布。

## 本地预览

直接打开 `index.html`，或在仓库目录运行任意静态服务器。
