# Achievement Unlock Intro Generator

一个可部署到 GitHub Pages 的纯前端工具，用于生成“游戏成就跳出卡片”风格的 Logo 介绍图片。

## 产品定位

面向同人周边、游戏社群、活动视觉、新品发布、虚拟角色设定页等场景，用户无需设计软件，即可通过上传 Logo、填写标题与介绍文案，生成具有游戏成就提示感的 300dpi PNG 图片。

## 核心功能

- 上传 Logo 图片
- 输入主标题、副标题、介绍文案和可留空的底部标签
- 横版、方图、竖版三种 300dpi 画布规格
- 内置四类风格预设：暗绿成就、鎏金典藏、霓虹赛博、羊皮幻想
- 支持逐元素更换背景色、强调色、边框色、文字色
- 默认关闭内置装饰，支持按需调整装饰强度
- 支持上传自定义底纹 / 背景图，并调整底纹透明度
- 支持调整卡片透明度和 Logo 在画布中的缩放比例
- 支持切换中文字体，也可上传自定义字体文件
- 所见即所得 SVG 预览
- 导出 300dpi PNG 和 SVG

## GitHub Pages 部署

仓库无需构建，直接使用静态文件即可：

1. 将代码推送到 GitHub 仓库。
2. 打开仓库 Settings → Pages。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/root`。
5. 保存后等待 Pages 发布。

## 本地预览

直接打开 `index.html`，或在仓库目录运行任意静态服务器。
