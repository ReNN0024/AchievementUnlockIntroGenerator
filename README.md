# Achievement Unlock Intro Generator

> 以游戏成就解锁的叙事结构，生成一张具有 Apple 系统磨砂玻璃质感的品牌 / Logo 介绍卡片。

**Achievement Unlock Intro Generator** 是一个无需后端、可直接部署到 GitHub Pages 的纯前端创作工具。上传底图与 Logo，编辑标题、成就文案和排版，再导出 `1932 × 1360` 的 PNG 或 SVG 成品。

它适合同人周边、游戏社群、活动 KV、新品发布、角色设定、品牌介绍和社交媒体封面等需要“成就解锁感”的视觉场景。

---

## 核心体验

- **作品优先的创作界面**：中性、克制的编辑器界面退后，让底图与生成作品成为视觉焦点。
- **真实系统磨砂玻璃**：卡片会复制并模糊同一张底图，保留清透的背景细节、精确圆角、薄边框与柔和阴影，而非白色塑料或霓虹亚克力效果。
- **所见即所得**：网页预览、SVG 导出和 PNG 导出共用同一套 SVG 渲染结构，保证裁切、排版、玻璃效果和颜色的一致性。
- **直接在画布上调整**：点击底图或 Logo，即可拖动位置、滚轮缩放；面板中的数值控件会同步更新。
- **可恢复的创作过程**：支持撤销、重做、自动保存和刷新恢复，减少反复调试的成本。

## 快速开始

首次打开且没有本地存档时，编辑器会自动载入内置的**暝夜示例**（背景、Logo 与文案），可以直接导出，也可以作为调参起点。已有存档时优先恢复你自己的作品，示例不会覆盖它。

随时可以通过页面右上角或“内容”面板顶部的 **载入暝夜示例** 重新载入；载入前会提示，且属于一次可撤销操作（⌘/Ctrl+Z 即可回到之前的作品）。“新建空白作品”不会重新载入示例。

1. **上传底图**：在“底图”面板中点击上传卡片、拖入图片，或直接从剪贴板粘贴图片。
2. **上传 Logo**：使用同样的方式载入品牌标识、角色图形或徽章。
3. **编辑文案**：填写主标题、副标题和介绍文案；文案支持手动换行。
4. **调整素材构图**：
   - 点击预览中的底图或 Logo 选中对象；
   - 拖动改变位置；
   - 滚轮缩放；
   - 或使用面板的缩放 / 位置数值和“适应、填满、居中、复原”快捷操作。
5. **选择玻璃风格**：在“Liquid Glass”中使用清透、标准或深色预设；再按需要调节玻璃深度、透明度和色散。
6. **一键智能适配**：点击“智能适配底图”，会基于当前像素重新分析背景与 Logo，给出材质、强调色、文字色与卡片高度建议。
7. **检查排版并导出**：在预览工具栏中导出 PNG 或 SVG。

## 排版是如何居中的

系统通知版式采用**两阶段排版**：

1. **测量**：先用 `actualBoundingBoxAscent` / `actualBoundingBoxDescent` 取得每一段文字的真实字形边界（不可用时回退到 `fontSize × 0.78 / 0.22`），而不是用 font-size 近似视觉高度。
2. **排列**：由测量结果算出整个文字块的真实高度，让文字块**整体**围绕卡片中心垂直居中，再从 `textBlockTop` 反推每一行基线。

因此文字不会再从卡片顶部按固定偏移依次堆叠；卡片高度变化时，文字块会自动重新居中。Logo 与文字**各自独立**围绕卡片中心居中，不再强制“主标题顶部对齐 Logo 顶部”。

间距参数控制的是**可见距离**（字形边界之间的空白），不是基线差值：

| 参数 | 含义 | 自动值（按正文行数） |
| --- | --- | --- |
| 副标题到主标题 | 副标题字形底部 → 主标题字形顶部 | 24px |
| 主标题到分割线 | 主标题字形底部 → 分割线 | 48 / 54 / 60px |
| 分割线到正文 | 分割线 → 正文首行字形顶部 | 44 / 50 / 56px |
| 正文行距 | 正文相邻行基线差 | 54px |
| 文字整体垂直位置 | 仅用于视觉微调（−80~80） | +8 / +4 / 0px |

自动卡片高度：无正文 510px（隐藏分割线）、一行 570px、两行 630px、三行 700px。

## Logo 透明留白自动裁切

许多 Logo 的 PNG 画布远大于实际图形。上传后会把图片绘制到离屏画布（缩放到 256px 以内以兼顾移动端性能），扫描 alpha 通道，忽略 alpha < 16 的像素，计算非透明内容的 bounding box，并在四周补 6.5% 留白，最后只保存**归一化**的裁切区域（不会重复存储大图）。

渲染与缩放都基于裁切后的有效内容，而不是完整 PNG 画布 —— 内置的暝夜徽章仅占其 2048×2048 画布的 47%×54%，按整张缩放时只有约 150px，自动裁切后为约 246px。

- **Logo 裁切**：自动裁去透明留白 / 使用原始画布 / 自定义
- 只依据 alpha 裁切，不会自动去掉黑色或白色实色背景；完全不透明的图片保留原画布
- **Logo 缩放**范围 40%~500%（数值输入可到 600%），以有效内容中心为缩放中心，保持等比
- `floating` 样式仅受整张玻璃卡片裁切，放大后不会被旧的 logoBox 截断；`glass` 样式仍受玻璃容器裁切，容器尺寸由独立的 `logoContainerSize` 控制
- 超出卡片安全区域时，编辑界面会给出提示（该提示不会进入导出文件）

## 编辑功能详解

### 1. 内容与字体

- 可编辑主标题、副标题和介绍文案。
- 介绍文案支持手动换行；工具会使用真实字体宽度处理中文、英文、数字、空格和常用标点的混排换行。
- 主标题默认以 `80px` 排版，空间不足时会逐步缩小到 `56px`；若仍不足，会在编辑器中提示内容溢出。
- 正文超过文案框可容纳的行数时，预览和导出都会显示省略号，并给出明确提示。
- 可使用系统黑体、宋体、楷体、现代黑体风格，也可以上传 `TTF`、`OTF`、`WOFF` 或 `WOFF2` 自定义字体。
- 自定义字体的数据会嵌入导出的 SVG；PNG 导出会等待字体加载完成后再生成。

### 2. 底图裁切与透明度

底图是作品的视觉基础，支持：

- PNG、JPEG、WebP 格式；单文件最大 `20MB`。
- 点击上传、拖拽上传和剪贴板粘贴。
- 替换、移除与上传状态提示。
- 缩放、水平位置、垂直位置、不透明度调节。
- “适应”“填满”“居中”“复原”四种快捷构图操作。
- 在预览画布中直接拖动定位，滚轮缩放。

底图的裁切参数会同时用于画布背景和玻璃卡片内部的模糊背景，因此预览与导出保持一致。

### 3. Logo 裁切与样式

Logo 支持和底图相同的上传、替换、移除、拖拽、粘贴、缩放与位置调节能力，并提供两种展示方式：

- **悬浮**（默认）：Logo 直接放置在大玻璃卡片内，仅保留轻微阴影，适合已有完整底板或透明图形的 Logo。
- **玻璃底座**：为 Logo 增加独立的系统磨砂玻璃容器，适合需要从复杂底图中获得更稳定识别度的图形。

切换 Logo 样式不会改变已设置的缩放和裁切位置。

### 4. Liquid Glass 卡片

中间成就卡片采用系统面板式的磨砂玻璃结构：

- 在卡片区域复制当前底图，并应用真实背景模糊、轻微饱和度和对比度调整。
- 叠加低透明度中性玻璃染色、左上柔和高光和右下弱冷色反射。
- 使用统一圆角几何的 `2.5px` 外轮廓、`1px` 顶部高光和 `1px` 底部暗边。
- 接触阴影与环境阴影分离绘制，保持实体轮廓锐利。
- 不使用噪点、波纹、粗白边、毛边滤镜或霓虹外发光。

内置三种只影响玻璃参数的预设：

| 预设 | 适用场景 | 特点 |
| --- | --- | --- |
| 清透 | 高对比、细节较清晰的底图 | 较低模糊、较低染色、轻阴影 |
| 标准 | 大多数场景，默认预设 | 平衡的模糊、染色与阴影 |
| 深色 | 明亮、复杂、文字需要更稳的底图 | 更强的染色和可读性遮罩 |

手动修改玻璃深度、卡片透明度或边缘色散后，预设状态会显示为“自定义”。

> 边缘色散范围为 `0–20`，最多只产生 `1px` 的微弱色差；标准预设默认关闭色散。

### 5. 排版与预览控制

所有关键数值都同时提供滑杆、数字输入和单项复原：

- 副标题到主标题间距。
- 主标题到分隔线间距。
- 分隔线到正文间距。
- 正文行距。
- 副标题、主标题和正文字距。
- 文案框宽度与高度。
- 网页预览缩放比例。

“预览缩放”只影响网页中的显示大小，不影响最终导出尺寸。

### 6. 推荐配色

上传底图后，工具会从图片中提取候选颜色，并为每一组候选配上更易读的文字颜色。点击“推荐配色”中的任意方案即可同时应用强调色和文字色；当前选中方案会显示清晰的选中状态。

## 撤销、恢复与自动保存

### 撤销 / 重做

- 支持最近 `30` 个有效编辑状态。
- 支持预览工具栏中的撤销、重做按钮。
- 快捷键：
  - `Ctrl / Cmd + Z`：撤销
  - `Ctrl / Cmd + Shift + Z`：重做
  - `Ctrl / Cmd + Y`：重做
- 连续拖动滑杆、拖动画布素材时，会在一次操作结束后记录为一个历史步骤。

### 自动保存

- 普通参数保存到 `localStorage`。
- 底图、Logo 与自定义字体保存到 `IndexedDB`，避免图片数据占满普通浏览器存储。
- 刷新页面后，若存在已保存的工作，会自动恢复并提示。
- **恢复默认参数**：仅恢复调节参数，保留现有文字与素材。
- **恢复示例**：会清空上传素材和自定义字体，执行前需要确认。
- **新建作品**：清空当前内容与素材，执行前需要确认。

## 导出说明

### PNG

- 导出尺寸固定为 `1932 × 1360px`。
- 导出流程会等待网页字体与已上传图片完成解码，避免导出半成品。
- PNG 文件会写入 `pHYs` 元数据：`11811 pixels/m`，对应 `300dpi`。
- 导出期间按钮会显示“正在导出…”，并防止连续重复点击。
- 成功、图片加载失败、画布创建失败、PNG 编码失败等状态都会显示提示。
- 文件名格式：`主标题-1932x1360-YYYYMMDD-HHMMSS.png`，会自动清理系统不允许的字符。

### SVG

- SVG 与网页预览使用同一套结构和参数。
- 自定义字体会以 Data URL 的形式嵌入 SVG 的 `@font-face`，便于在支持 SVG 字体嵌入的环境中保持字体一致。
- 文件名同样会自动进行安全处理。

## 本地运行

项目不依赖构建工具或第三方框架，可直接以静态页面运行。

```bash
python3 -m http.server 8000
```

然后在浏览器中打开：

```text
http://localhost:8000
```

也可以直接打开 `index.html`；但建议使用静态服务器，以获得更稳定的字体、导出和浏览器存储行为。

---

## 部署到 GitHub Pages

1. 将项目推送至 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/root`。
5. 保存设置，等待 GitHub Pages 发布完成。

项目根目录中的 `.nojekyll` 可避免 GitHub Pages 对静态资源进行 Jekyll 处理。

## 浏览器兼容性说明

建议使用最新版 Chrome、Edge、Safari 或 Firefox。

- SVG 背景模糊、PNG DPI 元数据写入、`FontFace` 和 IndexedDB 依赖现代浏览器能力。
- 在无痕模式、严格隐私模式或禁用 IndexedDB 的环境中，刷新后可能无法恢复已上传素材。
- 个别 SVG 查看器可能不支持滤镜或自定义字体内嵌；在浏览器中打开导出的 SVG 通常可以获得最完整的效果。
- 触控设备可使用单指拖动画布素材；不同移动浏览器对双指缩放与系统手势的处理存在差异，建议优先使用面板中的缩放数值进行精确调整。

## 技术栈

- HTML / CSS / 原生 JavaScript
- SVG：预览、玻璃渲染和 SVG 导出

- 无后端、无 React / Vue 等前端框架，可直接静态部署
